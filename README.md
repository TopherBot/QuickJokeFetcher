# QuickJokeFetcher

A **tiny** command‑line utility that grabs a random joke from the free [JokeAPI](https://v2.jokeapi.dev/) and prints it.

## Features
- Zero‑dependency (uses Python's standard library only).
- Supports both single‑line (setup/delivery) and two‑part jokes.
- One‑line installation and instant usage.

## Installation
```bash
# Clone the repo (or copy the single file)
git clone https://github.com/yourusername/QuickJokeFetcher.git
cd QuickJokeFetcher
# No extra packages required – just Python 3.7+
``` 

## Usage
```bash
python3 joke_fetcher.py
```
You will see something like:
```
Why did the scarecrow win an award?
Because he was outstanding in his field!
```

## Customisation
Edit `joke_fetcher.py` to change the API endpoint, add filters, or integrate into other scripts.
